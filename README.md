# GoProx 🌀

GoProx is a simple command-line tool written in Go that allows you to **toggle** and **check** your system proxy settings on Windows.

## ⚙️ Features

- ✅ View current proxy status
- 🔁 Enable or disable system proxy
- ⚡ Fast and lightweight (single binary)
